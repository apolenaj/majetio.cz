# Internal Linking — Majetio.cz

## Cíle

- Propojit objevování → analýzu → rozhodování → služby
- Posílit důvěru (metodika, zdroje) bez fake social proof
- Nepřetěžovat navigaci — hlubší odkazy ve footeru a kontextu stránky

## Páteřní odkazy

| Z | Kam | Proč |
| --- | --- | --- |
| Homepage | `/analyza`, `/nemovitosti`, `/jak-to-funguje` | Primární cesty |
| Detail nemovitosti | `/analyza`, `/porovnani`, `/cenik`, metodika | Akce + důvěra |
| Strategie | `/nemovitosti`, relevantní kalkulačky, `/analyza` | Kontext → akce |
| Ceník | `/analyza`, `/kontakt` | Konverze |
| Jak to funguje | `/analyza`, `/nemovitosti`, `/cenik` | Vzdělání → akce |
| Kalkulačky | `/analyza`, HypotekaJasne (financování) | Nástroj → rozhodnutí |
| Footer | kompletní mapa produktu | SEO + záchrana |

## Anchor text

Preferovat konkrétní: „Zobrazit metodiku výpočtu“, „Porovnat tuto nemovitost“.
Zakázáno: „klikněte zde“, holé „více“, „detail“.

## Hub & spoke

- Hub: `/strategie`, `/kalkulacky`, `/pruvodce`, `/lokality`
- Spoke: jednotlivé slug stránky zpět na hub + související CTA

## Co nelinkovat

- Mrtvé `#`
- Prod `/dev`
- Indexované thin search URLs
- Admin z veřejného footeru
