# Content Patterns — Majetio

Tone: `docs/TONE_OF_VOICE.md`

## CTA

- Analyzovat nemovitost
- Procházet nemovitosti
- Zobrazit výpočet
- Upravit předpoklady
- Přidat do porovnání
- Uložit nemovitost
- Spočítat financování
- Objednat kompletní analýzu

## Empty

- Zatím nemáte uložené žádné nemovitosti.
- Přidejte dvě nemovitosti a porovnejte jejich výnos, cenu a rizika.
- Dokončete finanční profil a zobrazíme vhodnější nabídky.

## Errors

- Nepodařilo se načíst aktuální data.
- Zkontrolujte připojení a zkuste to znovu.
- Pro tento výpočet chybí některé údaje.
- Hodnotu upravte na číslo vyšší než nula.

## Data honesty

Demo / odhad / ověřeno vždy označit.  
Žádné garantované výnosy.  
Nedostatek dat → „Nedostatek dat pro spolehlivé skóre.“
