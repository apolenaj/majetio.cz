# Success fee — otevřené otázky k rozhodnutí

Dokument „Realitní inzertní systém“ uvádí procentní odměny, ale nevyjasňuje fakturační podmínky.  
**Automatické účtování zůstává vypnuté**, dokud nebudou rozhodnuty body níže.

| # | Otázka | Dopad |
| --- | --- | --- |
| 1 | Je jednorázová odměna za pronájem z jednoho měsíčního nájmu, nebo z jiného základu? | Výpočet částky |
| 2 | Je uvedená % sazba včetně / bez DPH? | Ceník a faktury |
| 3 | Kdy odměna vzniká (rezervace, podpis, zápis do KN, nastěhování)? | Ledger workflow |
| 4 | Jak se dokládá a přiřazuje dokončený obchod portálu? | Anti-fraud / attribution |
| 5 | Pravidla zrušení a náklady objednaných externích služeb | Refund / storno |
| 6 | Bydlení za výpomoc: kdo platí 1000 Kč a kdy? | Aktivace platby |
| 7 | Aukce: jsou příhozy právně závazné? | Aktivace ostré aukce |
| 8 | Sdílená investice: schválený právní/transakční model před přijetím peněz | KYC / escrow |

Do rozhodnutí: konfigurace balíčků + **nezávazné sjednání služby** (`SuccessFeeEngagement` draft), bez PSP charge.
